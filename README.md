## 🎯 প্রজেক্ট সম্পর্কে

Capital AI একটি আধুনিক, সম্পূর্ণ বাংলা-সমর্থিত AI টুলস প্ল্যাটফর্ম যেখানে আপনি পাবেন:

- 🎨 **ইমেজ টুলস** - জেনারেশন, এডিটিং, এনহান্সমেন্ট
- ✍️ **টেক্সট টুলস** - লেখা, অনুবাদ, সারাংশ
- 🎬 **ভিডিও টুলস** - স্ক্রিপ্ট, থাম্বনেইল, সাবটাইটেল
- 🎵 **অডিও টুলস** - স্পিচ টু টেক্সট, টেক্সট টু স্পিচ
- 📚 **শিক্ষা টুলস** - ফ্ল্যাশকার্ড, কুইজ, মাইন্ড ম্যাপ
- 🇧🇩 **বাংলাদেশী টুলস** - নামাজের সময়, বাংলিশ অনুবাদ, পোস্ট কোড

## 🚀 দ্রুত শুরু করুন

### স্থানীয় ডেভেলপমেন্ট

```bash
# প্রজেক্ট ক্লোন করুন
git clone https://github.com/yourusername/capital-ai.git
cd capital-ai

# ডিপেন্ডেন্সি ইনস্টল করুন
npm install

# ডেভেলপমেন্ট সার্ভার চালু করুন
npm run dev

# http://localhost:3000 এ খুলুন
```

## 🔧 প্রযুক্তি স্ট্যাক

- **Frontend:** Next.js 14, React 18, TypeScript
- **Styling:** Tailwind CSS
- **Auth:** Clerk
- **Database:** Supabase (PostgreSQL)
- **UI Components:** Custom + Shadcn
- **Deployment:** Vercel (CDN + Edge Functions)
